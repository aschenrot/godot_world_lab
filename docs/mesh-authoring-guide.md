# Mesh Authoring Guide

Author reusable tile meshes in:

```text
assets/source/tiles/dual_grid_tiles.blend
```

Normalize them into:

```text
assets/tiles/dual_grid_tiles.glb
```

The lab also tracks this headless source snapshot:

```text
assets/source/tiles/dual_grid_tiles_source.gltf
assets/source/tiles/dual_grid_tiles_source.bin
```

The source snapshot exists because CI/headless machines may not have Blender
available. Regenerate it from the `.blend` whenever the authored source changes.

The normalized GLB must contain these base mesh nodes:

```text
corner
edge
t
diagonal
full
debug
```

Author meshes around a consistent tile origin. Rotation comes from `godot_grid`
descriptor data as clockwise degrees. Do not author rotated variants such as
`corner_90` or `edge_180`; those are descriptor keys mapped to base meshes plus
runtime rotation.

The current source blend imports with these authored names:

```text
corner           -> corner
edge             -> edge
T                -> t
diagonal_corner  -> diagonal
full             -> full
```

`debug` is a normalized fallback mesh generated by
`tools/tilekit/normalize_dual_grid_tilekit.gd` until the authored source carries
a dedicated debug mesh.

Variants and materials belong to `TileMeshCatalog`, not to `grid` or
`spatial_streaming`.

`GridMap` and `MeshLibrary` can help inspect assets, but they must not become
the runtime topology or streaming source of truth.

Regenerate the normalized GLB with:

```sh
godot --headless --path . --script tools/tilekit/normalize_dual_grid_tilekit.gd
```
